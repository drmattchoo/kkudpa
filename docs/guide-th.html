DPA Claim Filler

ส่วนขยาย Chrome ช่วยกรอกขั้นตอนเบิกจ่ายค่าเดินทางไปราชการในระบบ KKU Business Travel (dpa.kku.ac.th) จากไฟล์หลักฐานที่ลงนามดิจิทัลแล้ว · เวอร์ชัน 0.2.5

สิ่งที่ผู้ใช้ต้องเตรียมมีอย่างเดียว: ไฟล์ PDF ที่ลงนามด้วย KKU Digital ID ใน Adobe Acrobat แล้ว หนึ่งไฟล์ต่อหนึ่งรายการเบิก เช่น
• ไฟล์ค่าโดยสารเครื่องบิน = ใบเสร็จ/ใบกำกับภาษี + บัตรขึ้นเครื่องขาไปและขากลับ
• ไฟล์ค่าที่พัก = ใบเสร็จ + folio
ค่าเบี้ยเลี้ยงไม่ต้องมีไฟล์ ใช้เวลาเดินทาง 4 ช่วงเท่านั้น
ส่วนขยายจะไม่กด บันทึกเอกสาร หรือ ส่งเอกสารขออนุมัติเบิกจ่าย ให้ ผู้ใช้ตรวจและกดเองเสมอ ส่วนขยายกดได้เฉพาะ เพิ่มรายการขอเบิก และ ล้างข้อมูล เท่านั้น

1. ติดตั้ง (ครั้งแรกครั้งเดียว)

  1. แตกไฟล์ zip ที่ได้รับ แล้วเก็บโฟลเดอร์ extension ไว้ในที่ที่จะไม่ลบ เช่น Documents (Chrome โหลดจากโฟลเดอร์นี้ทุกครั้ง)
  2. เปิด Chrome พิมพ์ chrome://extensions ในช่องที่อยู่
  3. เปิด Developer mode (มุมขวาบน)
  4. กด Load unpacked แล้วเลือกโฟลเดอร์ extension (ข้างในต้องมีไฟล์ manifest.json)
  5. กดไอคอนจิ๊กซอว์บนแถบเครื่องมือ แล้วปักหมุด KKU DPA Travel Claim Filler

Chrome อาจเตือนเรื่อง “developer mode extensions” ตอนเปิดโปรแกรม เป็นเรื่องปกติของส่วนขยายที่ติดตั้งแบบนี้ กดปิดได้

2. ใส่ API key ของตนเอง

  1. ขอ API key ของตนเองจาก KKU GenAI (KKU IntelSphere) ทุกคนใช้ key ของตัวเอง และนับโควตาของตัวเอง
  2. กดไอคอนส่วนขยายเพื่อเปิดแผงด้านข้าง ครั้งแรกจะเปิดที่หน้า ⚙
  3. วาง key ในช่อง Your API key key ถูกเก็บในเบราว์เซอร์นี้เท่านั้น ไม่ซิงก์ไปที่อื่น
  4. เลือกโมเดล ค่าเริ่มต้นคือ gemini-3.8-flash ซึ่งอ่านภาพสแกนได้

3. ใช้งานกับทริปหนึ่งทริป

  1. เปิดทริปใน DPA หน้าแรก > เอกสารรอดำเนินการ > ทริปที่สถานะ รอเบิกจ่าย > ลูกศร > Open Form
  2. 1 Trip กด Read trip from this page ตรวจว่าขึ้น Page check passed เลขที่ TRIP วันที่ และอัตราเบี้ยเลี้ยง/ค่าห้องพักถูกต้อง
  3. 2 Files ลากไฟล์ PDF ที่ลงนามแล้วมาวาง แล้วกด Read แต่ละไฟล์ต้องขึ้นป้ายเขียว signed: ชื่อผู้ลงนาม และแสดงเอกสารที่อ่านได้ข้างใน กดเลขหน้าเพื่อเทียบกับต้นฉบับ
  4. 3 Review
    • ตรวจเวลา 4 ช่วง (รูปแบบ พ.ศ. เช่น 10-11-2569 15:30) ค่าเริ่มต้นคือ เวลาขึ้นเครื่องขาไป −2 ชั่วโมง และเวลาถึงขากลับ +1 ชั่วโมง แก้ได้ แล้วติ๊ก I confirm these four times
    • ตรวจยอดแต่ละรายการ กด Where the numbers come from เพื่อดูว่าตัวเลขมาจากหน้าไหน แล้วติ๊ก I checked this line
    • ข้อความสีแดง (Must fix) ต้องแก้ก่อนจึงจะกรอกได้
  5. 4 Fill แนะนำให้ลอง Dry run ก่อน ส่วนขยายจะกรอกแผงรายการเบิกใน DPA แล้วเทียบยอดที่ DPA คำนวณกับยอดที่วางแผนไว้ โดยไม่เพิ่มรายการ กด ล้างข้อมูล ใน DPA ก่อนลองรายการถัดไป
  6. เมื่อยอดตรงทุกรายการ เลือก Add lines แล้วกดทีละรายการ ส่วนขยายจะกด เพิ่มรายการขอเบิก เฉพาะเมื่อยอดของ DPA ตรงกับแผนเท่านั้น
  7. ตรวจตารางค่าใช้จ่ายใน DPA ว่าคอลัมน์ SIGNED BY ขึ้นชื่อผู้ลงนาม แล้วกด บันทึกเอกสาร และ ส่งเอกสารขออนุมัติเบิกจ่าย ด้วยตนเอง

ถ้า DPA ไม่รับไฟล์อัตโนมัติ แผงด้านข้างจะแจ้งให้คลิกช่อง หลักฐานค่าใช้จ่าย ที่ถูกไฮไลต์ใน DPA แล้วเลือกไฟล์เดียวกันเอง ส่วนขยายจะรอ

4. กฎที่ส่วนขยายตรวจให้

รายการสิ่งที่กรอกสิ่งที่ตรวจ
ค่าเบี้ยเลี้ยงเวลา 4 ช่วง DPA คำนวณวันเองครบ 24 ชม. นับ 1 วัน เศษเกิน 12 ชม. นับเพิ่ม 1 วัน และเทียบจำนวนวันกับที่ DPA คำนวณ
ค่าที่พักจำนวนคืน × อัตราต่อคืนไม่เกิน จำนวนคืน × อัตราตามสิทธิ ถ้าใบเสร็จเกิน ต้องเขียนในใบเสร็จว่า “เบิกจ่ายเพียง … บาท” ก่อนลงนาม
ค่าโดยสารเครื่องบินค่าตั๋ว + ภาษีสนามบินไม่รวมค่าเลือกที่นั่ง สัมภาระ ประกัน ค่าธรรมเนียมชำระเงิน และบริการเสริมอื่น
ทุกรายการไฟล์ต้องลงนามแล้วและไม่ถูกแก้ไขหลังลงนาม ไม่เพิ่มรายการซ้ำกับที่มีใน DPA เทียบยอดรวมกับงบที่ขออนุมัติ

5. ข้อควรรู้

  • ข้อมูลส่วนบุคคล (PDPA): หน้าเอกสารถูกส่งไปยัง KKU GenAI ซึ่งส่งต่อให้ผู้ให้บริการของโมเดลที่เลือก โมเดลกลุ่ม KKU Local LLM (gemma4-…) ประมวลผลบนเซิร์ฟเวอร์ของมหาวิทยาลัย
  • ไฟล์ที่ลงนามจะถูกอัปโหลดเข้า DPA ตามต้นฉบับทุกไบต์ ลายมือชื่อดิจิทัลจึงยังใช้ได้
  • โมเดลอาจอ่านผิดได้ ตรวจทุกตัวเลขในหน้า Review ก่อนกรอกเสมอ
  • ถ้าอ่านไฟล์ไม่สำเร็จ เปิด How it was read ในการ์ดของไฟล์ แล้วส่งภาพหน้าจอให้ผู้ดูแล
  • ส่วนขยายนี้ยังอยู่ระหว่างทดลองใช้ ยังไม่ได้ทดสอบกับหน้า DPA จริงครบทุกขั้นตอน ควรใช้ Dry run ก่อนทุกครั้งในช่วงแรก

6. อัปเดตเวอร์ชันใหม่

  1. แทนที่ไฟล์ในโฟลเดอร์ extension ด้วยไฟล์จาก zip ใหม่
  2. ไปที่ chrome://extensions แล้วกดปุ่มรีโหลด (ลูกศรวน) ที่การ์ดของส่วนขยาย
